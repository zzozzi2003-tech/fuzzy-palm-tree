Eleven Store - Discord Link Preview Patch

1) Replace your repository server.js with the server.js in this package.
2) Put public/discord-preview.png into your repository public folder.
3) Commit/push to GitHub and let Render deploy.
4) Share a product URL such as https://eleven-store-sa.onrender.com/product/<slug> in Discord.

Each product preview uses the product name, description, price and product image.
The homepage uses public/discord-preview.png as its preview image.

Note: Discord caches link previews. If an old preview remains, test a new product URL or append a harmless query string once, e.g. ?v=2.
