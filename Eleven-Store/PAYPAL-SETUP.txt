ELEVEN STORE - PAYPAL CHECKOUT v6.6.0

WHAT WAS ADDED
- PayPal button on Checkout.
- Server-side price calculation (the browser cannot choose the payment amount).
- PayPal Orders v2 create + capture flow.
- Automatic Delivered status after a verified COMPLETED capture.
- PayPal order/capture IDs saved with the store order.
- Customer Discord role assignment runs after a successful PayPal payment.
- Existing bank-transfer checkout remains as a fallback.
- Supabase persistence is kept in server.js.

IMPORTANT CURRENCY NOTE
PayPal REST does not support SAR as a transaction currency. The store still displays SAR, but PayPal is charged in USD by default.
PAYPAL_SAR_PER_UNIT=3.75 means 1 USD = 3.75 SAR.
Example: SAR 110.00 -> USD 29.33.

RENDER ENVIRONMENT
PAYPAL_CLIENT_ID=your Live PayPal Client ID
PAYPAL_CLIENT_SECRET=your Live PayPal Client Secret
PAYPAL_MODE=live
PAYPAL_CURRENCY=USD
PAYPAL_SAR_PER_UNIT=3.75

Keep your existing BASE_URL, Discord, and Supabase variables. Do NOT put PAYPAL_CLIENT_SECRET in public JavaScript or GitHub.

DEPLOY
1. Upload this version to the same GitHub project.
2. Add the five PAYPAL_* variables above in Render > Environment.
3. Save and deploy.
4. Render logs should show: [PAYPAL] ready | mode=live | currency=USD ...
5. Log in with Discord, add a product, open Checkout, enter phone/email, Continue, then use PayPal.

TEST FIRST (recommended)
To test without real money, use Sandbox app credentials and set PAYPAL_MODE=sandbox. After the test succeeds, swap to Live credentials and PAYPAL_MODE=live.
